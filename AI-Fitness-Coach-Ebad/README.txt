AI Fitness Coach - Hackathon Static Demo

How to run:
1. Open this folder in VS Code.
2. Double-click index.html, OR right-click index.html -> Open with Live Server if you have that extension.
3. The website works without Node, React, MongoDB or an API.

Included demo sections:
- User Dashboard
- AI Body Analysis / 4 photo uploads
- Goal selection
- Diet + workout plan
- Daily habit tracker
- AI Coach chat (demo responses)
- Weekly progress
- Admin dashboard with user management

Important:
This is a front-end hackathon prototype. AI body analysis, authentication, database, real OpenAI/Gemini calls, MediaPipe and real-time Socket.IO are represented as demo UI only.
